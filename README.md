# ParamFinder
A Cloud-Agnostic Orchestration Layer for Asynchronous Hyperparameter Optimization

# About
Machine learning and deep learning models require strategic tweaking in its hyperparameters, but findng the right one require N times iterations. ParamFinder solves this
by orchestrating asynchronous hyperparameter optimization across consented remote computers in a decentralized network without shouldering the compute on your own.
